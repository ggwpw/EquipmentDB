# 🖥 Окна, страницы и диалоги

---

## Окна верхнего уровня (Window)

### LoginWindow
**Файл:** `Views/LoginWindow.xaml` + `.cs`  
**VM:** `LoginViewModel`  
**Функции:**
- Поля Логин + Пароль (PasswordBox)
- Enter → вход
- Блокировка кнопки при пустом логине
- Отображение ошибки (`ErrorMessage`)
- При успехе → открывает `MainWindow`, закрывается сам

---

### MainWindow
**Файл:** `Views/MainWindow.xaml` + `.cs`  
**VM:** `MainViewModel`  
**Структура:**
```
┌─────────────────────────────────────────┐
│ Sidebar (210px) │ TopBar (заголовок)    │
│ ─ Логотип       │─────────────────────  │
│ ─ Навигация     │ ContentControl        │
│                 │ (текущая страница)    │
│ ─ Юзер + Выход  │                       │
└─────────────────────────────────────────┘
```
**Навигация:** кнопки меняют `CurrentView` в VM → DataTemplate подбирает нужный UserControl.  
**Пользователи/Журнал** скрыты для не-администраторов.

## Страницы (UserControl)

Все страницы в `Views/Pages/`, code-behind в `Pages.xaml.cs`.

### EquipmentPage — Оборудование
**VM:** `EquipmentViewModel`  
**Элементы:**
- Поиск (по названию и инв. номеру)
- ComboBox фильтр по классу
- ComboBox фильтр по состоянию
- Кнопка «Сбросить фильтры»
- Кнопки: + Добавить, ✏ Изменить, 🗑 Удалить, 📥 Excel
- DataGrid с колонками: Инв.номер, Название, Тип, Класс, Состояние (цветная точка), Дата поступления
- Кнопки редактирования скрыты для `observer`

---

### RoomsPage — Классы и сотрудники
**VM:** `RoomsViewModel`  
**Структура:** два DataGrid бок о бок (50/50)  
- Левый: Классы (Кабинет, Название, Вместимость) + кнопки CRUD
- Правый: Сотрудники выбранного класса (ФИО, Должность, Телефон) + кнопки CRUD
- Выбор класса обновляет список сотрудников

---

### UsersPage — Пользователи
**VM:** `UsersViewModel`  
**Доступ:** только `admin`  
**Элементы:**
- Кнопки: Добавить, Изменить, Блок/Разблок, Сбросить пароль
- DataGrid: Логин, Роль, Сотрудник, Статус (цветной), Создан, Попыток

---

### EventLogPage — Журнал событий
**VM:** `EventLogViewModel`  
**Доступ:** только `admin`  
**Фильтры:** DatePicker «С» и «По» + поиск по логину пользователя  
**DataGrid:** Время, Пользователь, Событие, Описание, Таблица

---

### ReportsPage — Отчёты
**VM:** `ReportsViewModel`  
**Доступ:** все роли  
**Элементы:** ComboBox выбора отчёта + кнопка Обновить + DataGrid с AutoGenerateColumns  
**Отчёты:** см. [[Reports]]

## Диалоги (Window, ShowDialog)

Все диалоги в `Views/Dialogs/`, code-behind в `Dialogs.xaml.cs`.  
Возвращают `DialogResult = true` при сохранении, `false` при отмене.

### EquipmentDialog — Добавление/редактирование оборудования
**VM:** `EquipmentDialogVm` (внутренний класс)  
**Вкладки:**
1. **Основное** — Инв. номер*, Название*, ComboBox Типа*, ComboBox Класса*, ComboBox Состояния*, DatePicker
2. **Характеристики** — TextBox (multiline) для specs
3. **Фото** — путь к файлу + кнопка «Обзор...» + превью Image

**Валидация:** проверка обязательных полей перед SaveChanges  
**Предупреждение при закрытии:** если поля заполнены → «Есть несохранённые данные»

---

### RoomDialog — Класс
Поля: Номер кабинета*, Название*, Вместимость

---

### StaffDialog — Сотрудник
Поля: ФИО*, Должность, Телефон, Email, ComboBox Класса  
RoomCombo инициализируется в code-behind: `RoomCombo.ItemsSource = ctx.Rooms...`

---

### UserDialog — Пользователь
Поля: Логин*, PasswordBox (только при создании), ComboBox Роли*, ComboBox Сотрудника  
При редактировании: PasswordBox игнорируется (только логин/роль/сотрудник)

---

### ResetPasswordDialog — Сброс пароля
Поля: Новый пароль*, Подтверждение*  
Валидация: совпадение паролей + минимум 4 символа  
Результат: `dlg.NewPassword` доступен после `ShowDialog() == true`
