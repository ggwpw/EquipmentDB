## Решённые ошибки

## ERR-001: Повторяющееся имя Excel-файла

**Статус:** 🟢 Решена  
**Файл:** `ViewModels/ReportsViewModel.cs`, `ViewModels/EquipmentViewModel.cs`  
**Описание:** При экспорте дважды за день имя файла совпадало (`отчёт_20250425.xlsx`), SaveFileDialog предлагал перезаписать.  
**Причина:** Формат даты `yyyyMMdd` — без времени.  
**Решение:** Изменён формат на `yyyyMMdd_HHmmss` — теперь имя уникально до секунды.  
**Дата решения:** 2026-04-25

---

## Известные ограничения (не баги)

- **Фото оборудования:** хранится путь к файлу, а не сам файл. При переносе приложения на другой ПК пути станут недействительными.
- **Резервное копирование:** требует наличия `mysqldump` в PATH системы. На машинах без MySQL Client может не работать.
- **Экспорт Excel:** экспортирует текущий отфильтрованный список, а не все записи.
