## Известные ограничения (не баги)

- **Фото оборудования:** хранится путь к файлу, а не сам файл. При переносе приложения на другой ПК пути станут недействительными.
- **Резервное копирование:** требует наличия `mysqldump` в PATH системы. На машинах без MySQL Client может не работать.
- **Экспорт Excel:** экспортирует текущий отфильтрованный список, а не все записи.
