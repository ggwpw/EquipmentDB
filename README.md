# Учёт оборудования компьютерных классов

Десктопное приложение на WPF + MySQL для учёта компьютерного оборудования в учебном заведении.

**Студент:** Галкин Владислав (ИСиП3/1)  
**Дисциплина:** Технология разработки и защиты базы данных  
**Платформа:** .NET 8 / WPF + MySQL 8  
**Архитектура:** MVVM

## Структура репозитория

| Папка | Содержимое |
|---|---|
| `/` | Исходный код WPF-приложения |
| `database/` | SQL-скрипт создания и заполнения БД |
| `docs/` | ТЗ и проектная документация |
| `docs/obsidian/` | Контекст проекта в markdown (для AI и навигации) |

## Быстрый старт

1. Запустить `database/init.sql` в MySQL Workbench
2. Создать `config.json` рядом с `.exe`:
```json
{
  "ConnectionString": "Server=localhost;Port=3306;Database=equipment_db;User=root;Password=ВАШ_ПАРОЛЬ;CharSet=utf8mb4;"
}
```
3. Открыть `EquipmentDB.csproj` в Visual Studio 2022
4. `Ctrl+F5` — запуск
